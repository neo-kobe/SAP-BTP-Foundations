## About This Project

Welcome to my SAP BTP Foundations & Integration Lab!

This repository documents my learning journey as I build foundational skills in cloud computing, SAP Business Technology Platform (SAP BTP), application integration and data management.

With a BSc in Computing, I am refreshing and developing my technical knowledge while working towards a career in SAP BTP and Integration.

The purpose of this repository is to apply theoretical knowledge through practical exercises, document my progress and gradually build a technical portfolio.

## Learning Objectives

Through this project, I aim to:

- Understand cloud computing concepts and architecture.
- Explore SAP Business Technology Platform and its services.
- Understand HTTP protocols and REST APIs.
- Practise reading and working with JSON data.
- Refresh SQL and database management skills.
- Develop familiarity with Git and GitHub.
- Understand how business applications exchange information.
